# kashu.ecomauto Autofill extension

1. Open `chrome://extensions` in Chrome, Edge or Brave.
2. Turn on **Developer mode**.
3. Click **Load unpacked** and select this `extension` folder.
4. Pin **kashu.ecomauto Autofill**.
5. Open a listing form in Meesho Supplier or Flipkart Seller Hub, save your profile in the popup, and click **Fill current seller page**.

The extension only fills matching empty fields on supported seller pages. It does not read or store passwords, cookies, login tokens or submitted listings. Marketplace forms can change, so always review all values before submission.
