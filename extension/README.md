# kashu.ecomauto Autofill extension

1. Open `chrome://extensions` in Chrome, Edge or Brave.
2. Turn on **Developer mode**.
3. Click **Load unpacked** and select this `extension` folder.
4. Pin **kashu.ecomauto Autofill**.
5. Open a listing form in Meesho Supplier or Flipkart Seller Hub, save your profile in the popup, and click **Fill business details**.
6. To reuse a listing, fill the safe product fields once and click **Capture listing**. Open another supported listing page and click **Autofill listing**.

The extension is free and has no licence check. It only fills matching empty fields on supported seller pages. Password, OTP, token, email, phone, banking and identity fields are excluded from listing capture. Captured listing values stay in Chrome local extension storage until you clear them. Marketplace forms can change, so always review all values before submission.
